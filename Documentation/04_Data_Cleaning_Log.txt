## 12. Outlier Detection — Pdays

**Method used:** Interquartile Range (IQR)

| Measure | Value |
|---|---:|
| Q1 | -1 |
| Q3 | -1 |
| IQR | 0 |
| Lower Bound | -1 |
| Upper Bound | -1 |
| Lower Outliers | 0 |
| Upper Outliers | 8,257 |
| Total Potential Outliers | 8,257 |

### Interpretation

A total of 8,257 records (approximately 18.26% of the dataset) were flagged as potential outliers. Both Q1 and Q3 equal -1, resulting in an IQR of zero.

The value -1 indicates that a customer was not previously contacted. Values greater than -1 represent customers who had previous campaign contact. Consequently, all positive values were flagged by the IQR method.

### Cleaning Decision

All records were retained. The value -1 is a meaningful indicator of no previous contact, while positive values represent valid campaign history. No pdays values were deleted or modified.

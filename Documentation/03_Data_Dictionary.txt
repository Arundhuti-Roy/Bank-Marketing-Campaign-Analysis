# Data Dictionary

## Dataset: Bank Marketing

Total records: 45,211

Total attributes: 17 (16 input variables + 1 target variable)

### 1. Customer Information

| Variable | Description | Data Type |
|---|---|---|
| age | Customer's age | Numeric |
| job | Type of occupation | Categorical |
| marital | Marital status | Categorical |
| education | Education level | Categorical |
| default | Whether the customer has credit in default | Categorical (Yes/No) |
| balance | Average yearly account balance in euros | Numeric |
| housing | Whether the customer has a housing loan | Categorical (Yes/No) |
| loan | Whether the customer has a personal loan | Categorical (Yes/No) |

### 2. Current Campaign Information

| Variable | Description | Data Type |
|---|---|---|
| contact | Communication method used to contact the customer | Categorical |
| day | Day of the month of the last contact | Numeric |
| month | Month of the last contact | Categorical |
| duration | Duration of the last contact in seconds | Numeric |
| campaign | Number of contacts made during the current campaign | Numeric |

### 3. Previous Campaign Information

| Variable | Description | Data Type |
|---|---|---|
| pdays | Number of days since the customer was last contacted in a previous campaign; -1 indicates no previous contact | Numeric |
| previous | Number of contacts made before the current campaign | Numeric |
| poutcome | Outcome of the previous marketing campaign | Categorical |

### 4. Target Variable

| Variable | Description | Data Type |
|---|---|---|
| y | Indicates whether the customer subscribed to a term deposit | Categorical (Yes/No) |

### 5. Data Quality Considerations

- The original documentation reports no missing attribute values.
- Some categorical variables contain the value 'unknown', which requires investigation.
- The value -1 in pdays represents customers who were not previously contacted.
- The duration variable represents call duration and is only known after the call.
- The original data types and category values will be verified during data inspection and cleaning.

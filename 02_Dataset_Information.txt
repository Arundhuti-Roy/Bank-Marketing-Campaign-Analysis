# Dataset Information

## 1. Dataset Name
Bank Marketing

## 2. Original Source
UCI Machine Learning Repository

## 3. Dataset Link
https://archive.ics.uci.edu/dataset/222/bank+marketing

## 4. Dataset Description
The dataset contains historical records of telephone-based marketing campaigns conducted by a banking institution to promote term deposit subscriptions.

It includes customer demographic information, financial and employment-related attributes, campaign contact details, previous campaign interactions and the final subscription decision.

For this project, the dataset will be analysed from the perspective of a bank seeking to understand customer behaviour, evaluate marketing campaign effectiveness and improve customer targeting strategies.

## 5. Dataset Used
bank-full.csv

- Number of records: 45,211
- Target variable: y
- Target categories: yes / no
- File format: CSV

## 6. Supplementary Files
- bank.csv: Smaller version of the dataset.
- bank-names.txt: Dataset variable descriptions and additional information.
- bank-additional: Supplementary dataset containing additional campaign records and attributes.

## 8. Important Notes
- The original dataset contains historical campaign data from a Portuguese banking institution.
- The business problem and recommendations will be discussed in a general banking context.
- The analysis will be limited to the variables available in the dataset.
- The findings represent historical associations and should not be interpreted as proof of causation.
- The supplementary dataset will not be combined with the primary dataset without a clear analytical justification.
